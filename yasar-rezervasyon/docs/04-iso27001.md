# ISO/IEC 27001:2022 Uyum Notları

Bu doküman, sistemde ISO/IEC 27001:2022 **Ek A** kontrollerinin hangi teknik önlemlerle karşılandığını ve hangilerinin
**kurumsal süreç** (Bilgi İşlem / Bilgi Güvenliği / Hukuk) gerektirdiğini gösterir.

> ISO 27001 bir **yönetim sistemi** standardıdır; tek başına bir yazılım "ISO 27001 uyumlu" olamaz. Uyum, kurumun BGYS'si
> (risk değerlendirmesi, politikalar, iç denetim) ile sağlanır. Bu uygulama, BGYS kapsamına alınmaya hazır olacak şekilde
> **güvenli tasarım** ilkeleriyle geliştirilmiştir.

## 3. Üretim kurulum kontrol listesi

- [ ] `APP_ENV=production`, `APP_DEBUG=false`
- [ ] `APP_KEY` üretildi ve kasada (vault) yedeklendi
- [ ] HTTPS sertifikası; `SESSION_SECURE_COOKIE=true`
- [ ] `LDAP_DRIVER=native`, `LDAP_HOST=ldaps://…` veya `LDAP_START_TLS=true`, `LDAP_CA_CERT` tanımlı
- [ ] LDAP servis hesabı **yalnızca okuma** yetkili
- [ ] MySQL kullanıcısı yalnızca bu veritabanına yetkili; `audit_logs` trigger'ları kurulu (`SHOW TRIGGERS`)
- [ ] `storage/` ve `bootstrap/cache` dışında web sunucusu kullanıcısının yazma yetkisi yok; web kökü yalnızca `public/`
- [ ] Zamanlayıcı: `* * * * * php artisan schedule:run`
- [ ] Kuyruk işçisi: `php artisan queue:work --tries=3` (systemd/supervisor)
- [ ] Günlük veritabanı yedeği ve geri dönüş testi
- [ ] Hukuk Biriminin KVKK metni yayımlandı (taslak metin kaldırıldı)
- [ ] `php artisan config:cache route:cache view:cache`
